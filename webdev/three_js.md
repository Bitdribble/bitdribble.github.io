[Three.js](https://threejs.org/) - JavaScript library for 3D graphics in the browser, on top of WebGL and WebGPU. [GitHub](https://github.com/mrdoob/three.js)

#### Docs
* [Docs](https://threejs.org/docs/), [Manual](https://threejs.org/manual/), [Examples](https://threejs.org/examples/)
* [Forum](https://discourse.threejs.org/)

#### Tutorials
* Bruno Simon: [Three.js Journey](https://threejs-journey.com/)

#### Related Libraries
* [React Three Fiber](https://r3f.docs.pmnd.rs/) - React renderer for Three.js, with helpers in [drei](https://github.com/pmndrs/drei)
* [Rapier](https://rapier.rs/) - physics engine in Rust, compiled to WebAssembly for the browser
* [Vite](https://vite.dev/) - build tool and dev server
